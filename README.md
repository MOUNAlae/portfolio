# Portfolio technique - Mohamed Alae Mountassir

Site personnel publié avec GitHub Pages.

## Contenu

- `index.html` : page principale du portfolio ;
- `assets/screenshots/` : visuels techniques optimisés ;
- `assets/favicon.svg` : icône du site ;
- `.nojekyll` : désactive le traitement Jekyll inutile pour ce site statique.

## Publication sur GitHub Pages

1. Ouvrir le dépôt `MOUNAlae/portfolio` sur la branche `main`.
2. Cliquer sur **Add file > Upload files**.
3. Téléverser le contenu de ce dossier à la racine du dépôt.
4. Valider avec le message : `Publish final general technical portfolio`.
5. Dans **Settings > Pages**, vérifier :
   - Source : `Deploy from a branch` ;
   - Branch : `main` ;
   - Folder : `/ (root)`.
6. Ouvrir `https://mounalae.github.io/portfolio/` puis effectuer `Ctrl + F5` si l'ancienne version reste en cache.

Le portfolio est volontairement général. Le CV transmis avec chaque candidature doit être adapté à l'offre.
